# Inception — design

## Architecture

```
                     ┌──────────────────────────────┐
  Supabase (Postgres)│ videos · video_stance        │
  BigQuery           │ creator_stance (analytics)   │
  Vertex AI          │ gemini-embedding-001         │
                     └──────────┬───────────────────┘
                                │  adapters (api/src/sources.ts)
                     ┌──────────▼───────────────────┐
  artifacts ────────►│ Dataset  (one shape)         │
  data/oriane        └──────────┬───────────────────┘
  data/analyses                 │  buildIndex
                     ┌──────────▼───────────────────┐
                     │ Derivation layer (derive.ts) │  eventImpact · buildFact · search
                     └──────────┬───────────────────┘
                     ┌──────────▼───────────────────┐
                     │ Resolvers (resolvers.ts)     │
                     └──────────┬───────────────────┘
                     ┌──────────▼───────────────────┐
                     │ GraphQL over HTTP (server)   │
                     └──────────────────────────────┘
```

## Key decisions

| # | Decision | Rationale | Alternative rejected |
|---|---|---|---|
| D1 | GraphQL single endpoint | The five pages ask for different nested shapes (fact→stories→targets; event→impact→candidates); GraphQL avoids five bespoke REST endpoints | REST per page (chatty, duplicated joins) |
| D2 | One `Dataset` shape behind adapters | Enables offline tests and Supabase swap without touching resolvers | Resolvers calling Supabase directly |
| D3 | Events/facts stay file-backed in v0.1 | They are generated artifacts regenerated by scripts; putting them in Postgres adds a sync problem with no benefit yet | Storing them in Supabase now |
| D4 | Derivation is deterministic, no model at request time | Latency, cost, reproducibility; labels already exist as artifacts | Live LLM calls per query |
| D5 | `changePct` nullable | A percentage with a zero baseline is undefined; faking 0 or 100 misleads | Returning 0 |
| D6 | Evidence mode reported (`exact`/`fuzzy`/`none`) | The brief requires quotes "word for word"; fuzzy acceptance must be visible | Hiding the distinction |
| D7 | Lexical search by default, embeddings opt-in | Vertex cost and latency stay explicit; offline tests stay deterministic | Always embedding |
| D8 | Read-only service | Writes belong to ingestion/analysis pipelines; keeps blast radius small | GraphQL mutations |

## Contract inventory

- Schema: `api/schema.graphql` (frozen at 0.1.0).
- Semantics doc: `docs/api-v0.1.md` §3 — the rules a client cannot infer.
- Data provenance: `api/src/sources.ts` records `origin` for every dataset and it
  is exposed on `/healthz`.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Sample is 217 videos, not 2,200 | Percentages differ from the brief's mock | Every response is a sample; share cards say "Not a poll" |
| OCR namesakes (Pierre vs Bernard Cazeneuve) | Wrong verdict attributed | Curated namesake guard; evidence shown |
| Event anchors are curated | Missed events (e.g. RN Orléans absent) | Discovery pass documented; two-line anchor addition |
| Fuzzy evidence | Could accept a paraphrase | Sentence-level containment ≥ 0.7, mode surfaced to the UI |
